# Changes

Log of necessary and big changes: architecture shifts, breaking changes,
dependency or stack swaps, data model changes. Small fixes belong in git history.
Newest entries first. Link to [architecture.md](architecture.md) and
[roadmap.md](roadmap.md) when a change affects them.

## Entry template

```
### YYYY-MM-DD: Short title
- **Type:** architecture | breaking | dependency | data | process
- **What changed:**
- **Why:**
- **Impact / migration:**
- **Docs updated:** architecture.md / roadmap.md / none
```
